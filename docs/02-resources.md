## إزاى تقرأ الترتيب

المصادر جوه كل عنصر **مرتبة بالترتيب اللى تتفرج بيه**، مش بالجودة.

| العلامة | المعنى |
|---|---|
| **أساسى** | اتفرج عليه كامل |
| **داعم** | يكمّل زاوية ناقصة |
| **مرجع** | ارجعله عند الحاجة، متتفرجش عليه بالترتيب |

## اقرأ ده قبل ما تبدأ

المحتوى العربى **ممتاز فى المراحل ٠ و١ و٣**، **متوسط فى ٢ و٤**، و**شبه معدوم فى مواضيع الإنتاج المتقدمة**. العناصر اللى فيها فجوة معلّمة صراحةً.

ودى مش مشكلة، دى حقيقة السوق: **الإنجليزى التقنى مهارة إجبارية** فى الشغل ده. استخدم العربى للفهم الأول، وحوّل للإنجليزى من المرحلة ٤ فصاعداً — وده بيحصل بعد سنة ونص من دلوقتى.

# المرحلة ٠ — الأساس والقرار

## Git و GitHub

1. **[كورس Git & GitHub](https://elzero.org/learn-git-and-github/)** — أكاديمية الزيرو · *أساسى*

   **ليه دى:** أسامة الزيرو بيشرح السبب قبل الأمر، وده بالظبط اللى محتاجه فى المرحلة دى.

2. **[كورس تعلم Git & GitHub فى ساعة](https://www.youtube.com/watch?v=fDkR0TDR9dI)** — غريب الشيخ · *داعم*
   تلخيص مكثف لكل الأساسيات فى جلسة واحدة.
   **ليه دى:** مش بديل عن الأول — استخدمه كمراجعة سريعة قبل ما تبدأ مشروع.

## سطر الأوامر و Linux

1. **[كورس Command Line مع Cmder](https://elzero.org/course-learn-command-line/)** — أكاديمية الزيرو · *أساسى*
   الفرق بين `Terminal` و`Shell` و`CMD`، التنقل، الملفات، الـ `pipes`.
   **ليه دى:** مختصر ومركّز — بيوصلك للكفاية المطلوبة من غير ما تضيع أسبوع.

2. **[Linux Crash Course](https://www.youtube.com/watch?v=pYdB2uG9pnE)** — الباشمبرمج | Hamed Esam · *داعم*
   **ليه دى:** سيرفرات الإنتاج كلها لينكس. مش محتاج تتقنه، محتاج تبطّل تخاف منه.

3. **[كورس أوامر لينكس بالعربى](https://www.youtube.com/playlist?list=PLKXgWkpknjelD9khRVlcwlopzX8hFfbeU)** — AL-Alamy Tube — ١٦ فيديو · *مرجع*

   **ليه دى:** أنضف مدخل عربى. الفرق بين `MySQL` و`PostgreSQL` فى المستوى ده شبه معدوم.

2. **[SQL Course For Beginners](https://www.youtube.com/playlist?list=PLxbVBWjVdAEj8TmOUKPG0avUmLqSoQOpf)** — كورسات فى البرمجة (Korsat X Parmaga) · *داعم*

## منهجية الاختيار والتحقق

- كل رابط هنا **اتفتح فعلياً** واتقرأ منه العنوان واسم القناة وعدد الفيديوهات، مش منقول من نتيجة بحث.
- اتشال مصدران ظهروا فى البحث: واحد كان معنون «جافا» وهو فعلياً كورس أندرويد، وواحد رابطه ميت.
- الأولوية اتدت للقنوات اللى ورا الشرح فيها **خبرة هندسية حقيقية**، ولسلاسل **مكتملة** مش فيديوهات متفرقة.
- الأرقام صحيحة وقت التحقق، وممكن تزيد لو صاحب القناة كمّل السلسلة.
