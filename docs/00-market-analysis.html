السياق: نصيحة شائعة فى الوسط التقنى المصرى — إن Java وSpring هما الطلب الأكبر فى مصر والشركات الدولية، مع عرض قليل ورواتب أفضل.

١. تفكيك النصيحة لأربع دعاوى

النصيحة الأصلية مدموجة، وكل جزء فيها درجة صحة مختلفة. الفصل ضرورى عشان القرار يبقى مبنى على الأجزاء الصح مش على المتوسط.

صح جزئياً

الدعوى الأولى — «الطلب الأكبر»

فى شريحة الـ backend المؤسسى، Java وSpring مسيطرين فعلاً. جهات التوظيف الرئيسية فى مصر:

القطاعأمثلة

لكن «الأكبر فى السوق كله» مبالغة:

  • .NET مساوى تقريباً لـ Java فى مصر — بنوك وحكومة وشركات كبيرة.
  • Python عندها طلب إجمالى أكبر دلوقتى بسبب موجة الـ AI.
  • Node/TypeScript مسيطرة على الشركات الناشئة.

الصياغة الدقيقة

Java هى الأكبر فى قطاع الـ enterprise backend، مش فى السوق ككل.

نص صح — أخطر جزء

الدعوى الثانية — «العدد قليل»

عدد اللى بيعرفوا Java فى مصر مش قليل. كل كليات الحاسبات بتدرّسها كلغة أولى، وتراكات ITI وNTI بتخرّج مئات سنوياً. سوق الـ junior Java مزدحم بقسوة.

اللى قليل فعلاً حاجة مختلفة تماماً:

مهندس عنده ٣ سنين فأكتر خبرة إنتاج حقيقية على Spring Boot، مع microservices وmessaging وtransactions معقدة وJVM tuning وتشخيص مشاكل تحت حمل.

الأرقام العالمية لسنة ٢٠٢٦ بتأكد الانقسام:

  • إعلانات وظائف الـ junior انخفضت حوالى ٦٧٪.
  • البطالة بين الـ senior engineers حوالى ١٪.
  • وظائف مكتوب عليها junior بتطلب فعلياً ١–٣ سنين خبرة.

الخلاصة

السوق مستقطب، مش ناقص. فيه فائض junior ونقص senior فى نفس الوقت.

الأثر على القرار: الدخول رهان ٢–٤ سنين، مش ٦ شهور. البوابة الأولى ضيقة جداً، واللى بعدها واسع جداً.

صح — بسبب مختلف

الدعوى الثالثة — «الراتب أفضل»

Java مبتدفعش أكتر لأنها Java. بتدفع أكتر لأن اللى بيوظفوا Java هم البنوك والـ fintech والأوفشور — وهى قطاعات بتدفع أعلى بغض النظر عن اللغة. مطور Node فى Paymob بياخد قريب جداً من مطور Java فى نفس المكان.

الارتباط بين Java والفلوس ارتباط قطاعى مش تقنى. الهدف الحقيقى دخول القطاع، واللغة وسيلة.

تحذير على البيانات

أرقام الرواتب المنشورة لمصر على Glassdoor مكسورة — ظهر فيها «EGP 5,125 سنوياً» لمطور Java، وده رقم شهرى متقروش غلط. متبنيش قرار على المواقع دى؛ استخدم بدلها شبكة معارف حقيقية وإعلانات فيها range معلن.

صح تماماً — أقوى نقطة

الدعوى الرابعة — «الشركات الدولية»

سوق الخليج البنكى — السعودية والإمارات — والأوفشور الأوروبى بيطلبوا Java/Spring بالاسم فى الإعلانات. Java هى أكتر مهارة backend قابلة للتصدير من مصر.

ودى النقطة اللى بتغيّر الوضع المادى فعلاً — مش الراتب المحلى، لكن دخل بالدولار أو اليورو. مع التضخم وتقلب العملة، المقارنة بين راتب محلى وراتب محلى تانى شبه عديمة المعنى.

٢. اللى النصيحة مقالتهوش

أ. الجزء الصعب مش اللغة

Java كلغة ممكن تتعلمها فى شهر–شهرين. الصعب هو المنظومة حواليها:

  • Spring Security والـ authentication/authorization
  • الـ transactions وحالات الفشل الجزئى
  • JPA / Hibernate وسلوكه غير البديهى — N+1 وlazy loading وdetached entities
  • الـ messaging والـ eventual consistency
  • الـ observability وتشخيص مشكلة فى production الساعة ٣ الفجر

الحاجات دى مبتتعلمش من كورس. بتتعلم من نظام بيقع.

ب. البُعد الأهم — الذكاء الاصطناعى

الـ boilerplate بتاع Java/Spring هو بالظبط النوع اللى الـ AI بيكتبه بامتياز — لغة مطوّلة، موثّقة بغزارة، ٢٥ سنة بيانات تدريب. يعنى الجزء «الكتابة» من الشغلانة دى هو أسرع جزء بيفقد قيمته السوقية.

اللى فاضل قيمته:

  • تصميم النظام والمقايضات المعمارية
  • نمذجة الداتا الصح من أول مرة
  • تشخيص سلوك غريب فى production
  • الحكم على كود مولّد — هل ده صح ولا يبان صح؟

الاستنتاج

لو هتتعلم Java، اتعلمها عميق. السطحى منها الـ AI خد مكانه خلاص.

٤. القرار الموصى به — لمبتدئ من الصفر

التوصية

امشى فى Java — مع وعى كامل بالمدة.

الأسباب، مرتبة:

  1. لو الهدف المهنى لسه غير محدد — الخيار اللى هدفه غير محدد لازم يكون الخيار بأوسع أبواب خروج. Java عندها: backend مؤسسى، وAndroid، وهندسة داتا — Kafka وSpark كلاهما JVM — وتحوّل سهل لـ Kotlin وScala. مفيش بديل بنفس عرض المخارج.

  2. كلغة أولى بتعلّم اللى غيرها بيخبّيه — الـ types، والـ OOP، وإدارة الذاكرة، والـ concurrency. والحاجات دى بالظبط هى اللى تخطّيها بيخلق الـ junior غير القابل للتوظيف فى ٢٠٢٦. اللغات «السهلة» بتأجل الألم مش بتلغيه.

  3. التعلم بمساعدة الـ AI — Java من أكتر اللغات اللى الـ AI بيشرحها صح، لأن كمية التوثيق والكود العام عنها ضخمة. ميزة حقيقية لمن بيتعلم بالطريقة دى.

الشروط اللى القرار ده مشروط بيها

القرار ده يبقى غلط لو كسرت أى شرط من دول:

  • توقّع ١٨–٣٠ شهر لأول وظيفة، مش ٦. لو مش قادر تتحمل المدة دى، Java مش الاختيار الصح.
  • ممنوع tutorial hell. الكورسات وسيلة، والدليل الوحيد على التقدم هو كود شغّال منشور.
  • ٢–٣ مشاريع حقيقية منشورة deployed، مش على localhost وخلاص.
  • متكتبش سطر مش فاهمه. الكود المولّد اللى ميقدرش تشرحه مش بتاعك، والإنترفيو بيكشف ده فى ٥ دقايق.
  • حدّد الهدف خلال أول شهرين. الهدف بيحدد المشاريع، والمشاريع بتحدد الـ CV.
