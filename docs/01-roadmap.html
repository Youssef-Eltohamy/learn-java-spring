خطة تنفيذ

من الصفر لوظيفة Java Backend

نقطة البداية المفترضة: الصفر — من غير stack سابق المدى الواقعى: ١٨–٣٠ شهر

الخطة دى مبنية على تحليل السوق. اقرأه الأول لو لسه ماقريتوش، لأنه بيفسر ليه الترتيب هنا كده.

القواعد الحاكمة

اقرأ القواعد دى قبل أى مرحلة. كسر أى واحدة فيهم بيحوّل الخطة لمجرد قائمة أمنيات.

  1. ٧٠٪ بناء / ٣٠٪ قراءة. لو النسبة اتعكست، إنت فى tutorial hell.
  2. كل مشروع يتنشر. localhost مش دليل على حاجة.
  3. متكتبش سطر مش فاهمه. خصوصاً المولّد بالـ AI.
  4. الـ AI يشرح، مش يكتب — فى المرحلة ٠ والمرحلة ١ تحديداً. بعد كده يبقى أداة إنتاج.
  5. متقفزش لـ Spring بدرى. ده أشهر خطأ. Spring بيحل مشاكل — لو معرفتش المشاكل دى بنفسك، Spring هيبقى سحر أسود بتحفظه.

  • تحديد الهدف — ريموت بالدولار؟ وظيفة محلية؟ خليج؟ ده بيحدد كل اللى بعده

مخرج المرحلة

المرحلة ١

Java Core خالص

٣–٤ شهور

ممنوع Spring نهائياً فى المرحلة دى. ممنوع أى framework.

  • الأساسيات — المتغيرات والشروط والحلقات والدوال
  • الـ OOP بعمق — classes وinterfaces وinheritance وpolymorphism وabstraction
  • الـ Collections — List وMap وSet وإمتى تستخدم إيه وليه
  • الـ Generics والـ Exceptions
  • Streams API والـ lambdas
  • File I/O
  • مقدمة concurrency — Thread وExecutorService ومشكلة الـ race condition
  • Maven — ليه موجود وإزاى يشتغل
  • JUnit 5 + Mockito — اكتب اختبارات من أول يوم

المشروع: تطبيق console بحجم حقيقى — مثلاً نظام إدارة مكتبة أو متتبع مصاريف. بيانات فى ملفات، منطق حقيقى، اختبارات.

اختبار الاجتياز

تقدر تشرح الفرق بين interface وabstract class وإمتى تختار كل واحد — من غير ما تفتح جوجل.

المرحلة ٢

الداتا والشبكة

٣–٤ شهور
  • SQL بعمق — joins وindexes وtransactions وnormalization وexecution plans
  • PostgreSQL — تثبيت وتشغيل واستخدام حقيقى
  • JDBC يدوى — اتصل بقاعدة بيانات من غير ORM، عشان تحس بالألم اللى JPA بيحله
  • REST من الأول — resources وverbs وstatus codes وidempotency
  • Servlet بسيط أو HTTP server يدوى — عشان تفهم إيه اللى Spring بيخبّيه
  • JSON والـ serialization

المشروع: API بسيط من غير Spring — endpoints قليلة، قاعدة بيانات حقيقية، JDBC يدوى.

اختبار الاجتياز

تكتب query فيها JOIN على ٣ جداول وGROUP BY من غير مساعدة، وتشرح ليه الـ index بيسرّعها.

المرحلة ٣

Spring Boot

٤–٦ شهور

دلوقتى بس، وبعد ما عرفت المشاكل بنفسك.

  • Spring Core — الـ IoC container والـ Dependency Injection والـ beans ودورة حياتها
  • Spring Boot — الـ auto-configuration وليه موجود
  • Spring Web — controllers وvalidation ومعالجة أخطاء موحّدة
  • Spring Data JPA — ومصايده: N+1 وlazy loading وdirty checking
  • Spring Security — JWT وroles وOAuth2 الأساسى
  • @Transactional — وإزاى بيفشل صح ولا غلط
  • Flyway لإدارة تغييرات قاعدة البيانات
  • Testcontainers لاختبارات تكامل حقيقية

المشروع الأول للـ CV

API كامل بـ authentication وroles وقاعدة بيانات حقيقية واختبارات، ومنشور على استضافة حقيقية، ومعاه README محترم.
